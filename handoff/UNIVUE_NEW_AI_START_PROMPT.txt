Current architecture
The deployed frontend is static HTML CSS and JavaScript on GitHub Pages. Supabase provides PostgreSQL, Auth, Row Level Security, restricted RPC functions, Realtime, Vault, and Edge Functions. A Raspberry Pi is the recommended touchscreen host and hardware controller. The physical button calls Supabase directly through the Pi service. LEDs and the thermal printer require the browser and hardware service to run locally on the same Pi unless a secure device queue is built later.
